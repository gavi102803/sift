Semantic Cache

How is it different from an exact-match cache?
Sift · deepseek-v4-flash
An exact-match cache only reuses an answer when the new request is a byte-for-byte match — so "capital of France?" and "France's capital?" miss and trigger a fresh call. A semantic cache embeds the query and reuses a stored answer when the meaning is close enough, measured by vector similarity
